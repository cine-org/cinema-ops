# 2. Root-application (app-of-apps, staging)

Mục tiêu: Argo CD tự đọc `k8s/environments/staging/applications` trong repo này và tự sync mọi Application khai báo bên trong — từ đây trở đi không `kubectl apply` tay từng thứ nữa, chỉ commit/push vào `cinema-ops`.

Root-application chỉ được apply **một lần bằng tay**, ngay bây giờ. Sau đó chính nó nằm dưới quyền quản lý của Argo CD (self-managed).

## 1. File `bootstrap/argocd/staging/root-application.yaml`

Đã có sẵn trong repo:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: root-staging
  namespace: argocd
spec:
  project: default

  source:
    repoURL: https://github.com/cine-org/cinema-ops.git
    targetRevision: main
    path: k8s/environments/staging/applications

  destination:
    server: https://kubernetes.default.svc
    namespace: argocd

  syncPolicy:
    automated:
      enabled: true
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
```

`path` trỏ vào thư mục hiện đang **rỗng** (chỉ có `.gitkeep`) — cố ý. Root sync sẽ hiện "Synced" với 0 resource; đây là bước xác nhận vòng lặp GitOps hoạt động trước khi nhét Application platform/app vào.

## 2. Apply một lần

Trên VPS:

```bash
export KUBECONFIG=$HOME/.kube/config
cd ~/cinema-ops
kubectl apply -f bootstrap/argocd/staging/root-application.yaml
```

## 3. Xác nhận trên UI

Mở lại tunnel như doc 1 bước 5 nếu chưa có, vào `https://localhost:8080`, thấy Application `root-staging` xuất hiện, status `Synced` + `Healthy` (dù chưa có resource con nào).

## 4. Từ đây trở đi

Muốn thêm platform (Postgres, Redis, Traefik config, cert-manager, sealed-secrets) hay app (`cinema`), chỉ cần:

1. Thêm file Application YAML vào `k8s/environments/staging/applications/`
2. Commit + push lên `main`
3. Argo CD tự phát hiện trong tối đa ~3 phút (polling mặc định, chưa cấu hình webhook) và tự sync

Không cần SSH vào VPS để `kubectl apply` nữa, trừ khi debug.
