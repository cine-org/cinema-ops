# 1. Bootstrap k3s + Argo CD (staging)

Mục tiêu: cài k3s + Argo CD trên VPS staging, đăng nhập được UI, chuẩn bị credential đọc repo. **Chưa** apply Application nào — root-application (app-of-apps) là doc 2.

## 1. Cài k3s

Pin cứng version (VPS này có thể thành prod sau này, cần lặp lại được y hệt):

```bash
curl -sfL https://get.k3s.io | INSTALL_K3S_VERSION=v1.36.3+k3s1 sh -
```

Không disable Traefik — dùng bản bundled sẵn theo thiết kế đã chốt.

Kiểm tra:

```bash
sudo systemctl status k3s
sudo k3s kubectl get nodes
```

Copy kubeconfig cho user `ops` dùng thẳng `kubectl` (không cần `sudo k3s kubectl`):

```bash
mkdir -p ~/.kube
sudo cp /etc/rancher/k3s/k3s.yaml ~/.kube/config
sudo chown ops:ops ~/.kube/config
chmod 600 ~/.kube/config
```

## 2. Cài Helm

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
```

## 3. Cài Argo CD

```bash
helm repo add argo https://argoproj.github.io/argo-helm
helm repo update
helm search repo argo/argo-cd --versions | head
```

- chọn version mới nhất, điền vào --version

```bash
helm install argocd argo/argo-cd \
  --version 10.4.0 \
  -n argocd --create-namespace \
  -f bootstrap/argocd/common-values.yaml \
  -f bootstrap/argocd/staging/values.yaml
```

## 4. Đăng ký credential đọc repo `cinema-ops` (private)

Tạo fine-grained PAT (khác `GHCR_PULL_PAT`): GitHub → Settings → Developer settings → Fine-grained tokens → New token. Resource owner `cine-org`, chỉ chọn repo `cinema-ops`, quyền `Contents: Read-only`.

```bash
export KUBECONFIG=$HOME/.kube/config
kubectl apply -f - <<EOF
apiVersion: v1
kind: Secret
metadata:
  name: cinema-ops-repo
  namespace: argocd
  labels:
    argocd.argoproj.io/secret-type: repository
stringData:
  type: git
  url: https://github.com/cine-org/cinema-ops.git
  username: x-access-token
  password: <PAT>
EOF
```

Chuẩn bị cho doc 2 (root-application sẽ đọc repo này) — GitHub App `argocd-cinema-ops-reader` để nâng cấp sau.

## 5. Lấy mật khẩu admin + truy cập UI qua SSH tunnel

```bash
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
```

```bash
kubectl -n argocd port-forward svc/argocd-server 8080:443
```

Từ máy local:

```bash
ssh -L 8080:localhost:8080 cinema-prod
```

Mở [UI](https://localhost:8080), đăng nhập `admin` + password ở trên.
