# 3. Platform resources (namespace)

Mục tiêu: tạo 2 namespace nền tảng cho staging — `cinema` (app: api/web-user/worker sau này) và `platform` (hạ tầng dùng chung: Postgres, Redis, Traefik config, cert-manager, sealed-secrets).

## Cách wiring vào Argo CD

1 Application riêng (`platform-resources`) trỏ vào `k8s/environments/staging/resources/`, không lồng vào `applications/platform/*` — vì đây là manifest thô (Namespace, sau này thêm ResourceQuota/ClusterIssuer), không phải Application con.

```text
root-staging (k8s/environments/staging/applications/)
  └── platform-resources.yaml → Application "platform-resources"
        source.path = k8s/environments/staging/resources
        └── namespaces.yaml (Namespace cinema, Namespace platform)
```

## File

`k8s/environments/staging/resources/namespaces.yaml`:

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: cinema
---
apiVersion: v1
kind: Namespace
metadata:
  name: platform
```

`k8s/environments/staging/applications/platform-resources.yaml`:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: platform-resources
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/cine-org/cinema-ops.git
    targetRevision: main
    path: k8s/environments/staging/resources
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      enabled: true
      prune: true
      selfHeal: true
    retry:
      limit: 5
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m
```

`retry` thêm do sự cố ở doc 4 — xem cuối doc 4.

`destination.namespace: default` không có ý nghĩa (Namespace là resource cluster-scoped) — chỉ để thoả schema Argo CD bắt buộc.

## Verify

```bash
kubectl get applications -n argocd
kubectl get namespace cinema platform
```
