# 3. Platform resources (namespace)

Mục tiêu: tạo 2 namespace nền tảng cho staging — `cinema` (app: api/web-user/worker sau này) và `platform` (hạ tầng dùng chung: Postgres, Redis, Traefik config, cert-manager, sealed-secrets).

## Quyết định namespace naming

Mỗi VPS là 1 cluster riêng biệt (staging và production không chung cluster) — xem `project-vps-topology` trong memory / mục 15 `p0.md`. Vì vậy namespace **không gắn hậu tố environment** (không phải `cinema-staging`), tên môi trường đã nằm ở cấp cluster (VPS nào) rồi, gắn thêm ở namespace là thừa và dễ gây lệch nghĩa nếu vai trò VPS đổi (đã từng xảy ra: VPS đổi alias từ `cinema-staging` sang `cinema-prod`).

## Cách wiring vào Argo CD

Theo đúng pattern học ở bài `hello`: 1 Application riêng (`platform-resources`) trỏ vào `k8s/environments/staging/resources/`, không lồng vào `applications/platform/*` — vì đây là manifest thô (Namespace, sau này thêm ResourceQuota/ClusterIssuer), không phải Application con.

```text
root-staging (k8s/environments/staging/applications/)
  └── platform-resources.yaml → Application "platform-resources"
        source.path = k8s/environments/staging/resources
        └── namespaces.yaml (Namespace cinema, Namespace platform)
```

## File

`k8s/environments/staging/resources/namespaces.yaml`:

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: cinema
---
apiVersion: v1
kind: Namespace
metadata:
  name: platform
```

`k8s/environments/staging/applications/platform-resources.yaml`:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: platform-resources
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/cine-org/cinema-ops.git
    targetRevision: main
    path: k8s/environments/staging/resources
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      enabled: true
      prune: true
      selfHeal: true
```

`destination.namespace: default` ở đây gần như vô nghĩa về mặt chức năng — `Namespace` là resource cluster-scoped (không thuộc namespace nào), field này chỉ tồn tại vì Argo CD schema bắt buộc phải có.

## Verify

```bash
kubectl get applications -n argocd
kubectl get namespace cinema platform
```
