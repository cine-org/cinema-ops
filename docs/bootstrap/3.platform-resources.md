# 3. Platform resources (namespace)

Mục tiêu: tạo 2 namespace nền tảng cho staging — `cinema` (app: api/web-user/worker sau này) và `platform` (hạ tầng dùng chung: Postgres, Redis, Traefik config, cert-manager, sealed-secrets).

## Cách wiring vào Argo CD

1 Application riêng (`platform-resources`) trỏ vào `k8s/environments/staging/resources/`, không lồng vào `applications/platform/*` — vì đây là manifest thô (Namespace, sau này thêm ResourceQuota/ClusterIssuer), không phải Application con.

```text
root-staging (k8s/environments/staging/applications/)
  └── platform-resources.yaml → Application "platform-resources"
        source.path = k8s/environments/staging/resources
        └── namespaces.yaml (Namespace cinema, Namespace platform)
```

## File

`k8s/environments/staging/resources/namespaces.yaml`:

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: cinema
---
apiVersion: v1
kind: Namespace
metadata:
  name: platform
```

`k8s/environments/staging/applications/platform-resources.yaml`:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: platform-resources
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/cine-org/cinema-ops.git
    targetRevision: main
    path: k8s/environments/staging/resources
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      enabled: true
      prune: true
      selfHeal: true
    syncOptions:
      - ServerSideApply=true
    retry:
      limit: 5
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m
```

`destination.namespace: default` không có ý nghĩa (Namespace là resource cluster-scoped) — chỉ để thoả schema Argo CD bắt buộc.

## Quy ước syncPolicy — áp cho mọi Application từ đây trở đi

2 field dưới không phải mặc định của Argo CD nhưng luôn phải có, thiếu là dính lỗi lúc dựng cluster mới:

- **`ServerSideApply=true`** — mặc định Argo CD apply client-side: nhét nguyên manifest vào annotation `last-applied-configuration` để lần sau so sánh. Chart kèm CRD lớn (external-secrets, CNPG, cert-manager) vượt trần 262144 byte của annotation → sync fail. Server-side apply để API server tự diff qua `managedFields`, không cần bản sao trong annotation.
- **`retry`** — Application dùng CRD do Application khác cài (`ClusterSecretStore` cần external-secrets, `Cluster` cần CNPG) sẽ fail lần sync đầu nếu operator chưa xong. `automated`/`selfHeal` không tự chạy lại một operation đã fail — nó chỉ sync khi có commit mới, phát hiện drift, hoặc bấm Sync tay. Thiếu `retry` là lúc dựng lại phải vào UI bấm Sync tay từng cái.

Chart cài vào namespace chưa tồn tại thì thêm `CreateNamespace=true`. `platform-resources` không cần — nó chính là thứ tạo namespace.

## Verify

```bash
kubectl get applications -n argocd
```
