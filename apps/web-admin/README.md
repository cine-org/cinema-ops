# web-admin

Web cho quản trị, domain `https://admin.cine.io.vn`. Image `ghcr.io/cine-org/setup-monorepo/web-admin`, port 80, health `GET /healthz`.

Tag và env ở `envs/staging/`. Chứng chỉ `admin-cine-io-vn-tls` do cert-manager tự xin.

Cách deploy và đổi version: [../docs/setup.md](../docs/setup.md).
